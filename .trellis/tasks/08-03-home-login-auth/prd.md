# 首页与登录鉴权

## Goal

为知微增加营销式首页与真实登录鉴权：未登录只能访问公开入口；本地单管理员登录后进入现有分析工作台。视觉复用当前工作台设计 tokens。

## Background

- 现行 `/` 为总览（`OverviewPage`）；`App.vue` 对所有路由统一侧栏+顶栏。
- 后端无用户模块；`/api/v1` 业务接口目前开放。
- `docs/prd.md` 原将「登录 / 多用户权限」标为一期不做；本任务有意扩展该边界。
- 设计 tokens：`frontend/src/style.css`（主色 `#0f766e`、Noto Sans SC）。

## Requirements

- R1. `/` 为营销首页：品牌「知微」、一句价值主张、「进入工作台 / 登录」CTA；无工作台侧栏。
- R2. `/login` 为独立登录页（无侧栏/顶栏壳）。
- R3. 总览迁至 `/overview`；侧栏与文档中的路由表同步更新。
- R4. 本地单管理员：凭证来自环境变量（无注册、无用户管理 UI）。
- R5. 后端提供登录、当前用户查询；业务 API（除健康检查与登录）未认证返回 401。
- R6. 前端路由守卫：未登录访问工作台 → `/login`（可带 `redirect`）；已登录访问登录页 → 工作台。
- R7. 工作台内可登出；登出后本地令牌清除，再访业务页需重新登录。
- R8. 首页与登录页视觉与现有 tokens / 控件气质一致。
- R9. 同步修订产品文档中「不做登录」表述与路由说明。

## Acceptance Criteria

- [ ] AC1. 未登录访问 `/overview` 及原工作台路径时，重定向到 `/login`。
- [ ] AC2. 使用配置的管理员凭证登录后可进入工作台；可登出。
- [ ] AC3. 无有效令牌调用受保护 API 返回 401；登录后可正常调用。
- [ ] AC4. `/` 为营销首页且无侧栏；风格使用现有 CSS 变量。
- [ ] AC5. `/overview` 总览可用，侧栏「总览」指向 `/overview`。
- [ ] AC6. 错误凭证登录失败并有可读错误提示；不泄露是否用户名或密码错误以外的内部细节。
- [ ] AC7. 现有 API 契约测试在鉴权夹具下仍通过；新增登录/守卫相关测试覆盖主路径。

## Out of Scope

- 多用户注册、角色权限、OAuth、找回密码、邮箱验证
- 服务端令牌吊销名单 / 多设备会话管理（JWT 登出以客户端丢弃为准）
- 将产品改造成多租户云 SaaS
- 首页 CMS / 多语言

## Key Decisions

| 决策 | 结论 |
|------|------|
| 鉴权深度 | 真鉴权：后端校验 + 前端守卫 + 登出 |
| 首页 | `/` 营销页；总览 → `/overview` |
| 账号 | 本地单管理员（环境变量），无注册 |
| 视觉 | 复用现有 design tokens |

## Risks / Notes

- 现有 pytest 用裸 `TestClient` 调业务 API，实现时需统一鉴权夹具，避免大面积失败。
- Axios 存在直连 `8001` 回退，宜用 `Authorization: Bearer` 而非跨源 Cookie。
