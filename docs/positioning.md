# 知微 — 定位与演进

> 回答三件事：**我们是谁**、**现在还算不算舆情分析**、**继续做成什么**。  
> 需求细节见 [PRD](./prd.md)。

---

## 1. 明确产品定位

### 1.1 定位陈述（对外可用）

**知微 = 本地部署的「观众反馈 / 内容口碑」分析工作台。**

- **主场景**：B 站等平台上，单条或一批内容的评论口碑（情感、主题、趋势、预警、报告）。
- **辅场景**：文件导入的多源文本、校园样例演示（**不**把产品锁死在校园舆情）。
- **形态**：Python（FastAPI + GPU 可选）+ Vue 工作台；数据与模型以本机为主。

### 1.2 定位坐标（和什么区分）

| 对比物 | 知微的位置 |
|--------|------------|
| 传统「全网舆情监测大屏」 | 更轻：按需采集 + 本地分析，不做政企级全网监听与多租户 |
| 纯爬虫 / MediaCrawler | 分析与报告是一等公民；爬虫是输入手段之一 |
| 通用 ChatBot | 助手基于**已入库舆情数据**问答/简报，不是开放域闲聊 |
| 仅情感分类 Demo | 具备监测→分析→预警→单视频口碑→导出的产品闭环 |

### 1.3 品牌与命名

| 名称 | 含义 |
|------|------|
| **知微** | 产品品牌（见微知著：从评论细节见口碑走势） |
| `yuqing` | 仓库/文件夹历史名，**不等于**「只做校园舆情」 |

## 2. 当前还算是舆情分析吗？

**算。而且核心仍是舆情 / 意见分析管线。**

更精确的说法：

> 知微是 **垂直在「内容观众反馈」上的舆情分析产品**，而不是泛化的社会危机舆情平台。

| 舆情分析要素 | 知微现状 |
|--------------|----------|
| 信息采集 | ✅ B 站评论、文件导入；可选外挂 MediaCrawler |
| 情感倾向 | ✅ BERT 三分类 + 难例复核 |
| 话题/主题 | ✅ 词云 + BERTopic |
| 时间趋势 | ✅ 滑动平均 / Prophet |
| 风险预警 | ✅ 负面、敏感词、热度突增 |
| 报告交付 | ✅ 汇总、单视频口碑、PDF/CSV、助手简报 |

**与「经典校园/政务舆情」的差异（刻意的）：**

- 对象从「机构声誉危机」偏向 **「单内容 / 创作者口碑」**；
- 校园包是**演示数据**，不是唯一业务域；
- 一期强调本地可演示、可答辩，而不是监管级覆盖面。

因此：对外介绍可说「社交媒体舆情与观众反馈分析」；对内研发应以 **口碑情报（Reputation / Audience Intelligence）** 为演进主轴，避免重新做大而全的舆情中台。

## 3. 进一步发展能做成什么？

按「能力半径」扩展，而不是换赛道。

### 3.1 近端（巩固口碑工作台）

- 多 BV / 合集对比、UP 维度聚合（同一创作者多稿口碑）
- 评论质量与水军信号更细（复用并加强现有 quality 门禁）
- 预警订阅（本地通知 / Webhook），报告模板品牌化
- 词典 vs BERT 对照实验表（Gate 已提示的可选下一步）
- 前端分层 spec（Trellis）与更完整的 API 契约测试 — **pytest 已加厚；frontend spec 已就位**
- **多 BV / UP 口碑对比**（任务 `.trellis/tasks/07-31-multi-bv-up-compare`）

### 3.2 中端（多平台观众情报）

- 在统一帖子模型上接入更多平台（抖音/微博等，经 MediaCrawler 或官方/半官方接口）
- 「内容发布 → 口碑跟踪」时间线：上线后 24h / 7d 口碑曲线
- 竞品或同话题内容的相对口碑（需合规采集边界）

### 3.3 远端（可演进的产品形态）

| 方向 | 一句话 | 仍依附的舆情内核 |
|------|--------|------------------|
| **创作者运营台** | 选稿、改简介、回评策略的数据依据 | 情感 + 主题 + 单视频报告 |
| **品宣/活动复盘** | 活动视频与话题的正负反馈与风险点 | 预警 + 趋势 + 导出 |
| **教学/科研沙箱** | 可替换模型的中文舆情实验床 | 全链路可观测、可导出 |
| **轻量 Agent 分析师** | 多步「先查库再归纳」的自动简报 | 现有 agent + 编排（需新目录边界） |

**不建议漂成：**

- 无分析内核的「又一个爬虫 GUI」
- 无数据接地的「通用大模型聊天站」
- 一上来的多租户云舆情 SaaS（除非单独立项）

## 4. 定位一句话备忘（答辩 / README 可用）

> **知微**：本地可运行的社交媒体**观众反馈与内容口碑**分析工作台——采集评论，做情感、主题与趋势，预警异常，输出单视频与全局报告。它属于舆情分析，主战场是内容口碑而非全网危机监测；下一步沿多平台、创作者维度与 Agent 简报加深，而不是改换品类。
